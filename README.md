# starhunter

Top-Down-Space-Shooter — schnell, bunt, mit Multiplayer (LAN & Online).

## Download & Installation

**[➜ Neueste Version herunterladen](https://github.com/mkreischer2000/starhunter-releases/releases/latest)**

1. Dort unter **Assets** die Datei `starhunter-setup-v….exe` herunterladen
2. Starten — falls Windows SmartScreen warnt: **„Weitere Informationen" → „Trotzdem ausführen"**
   (normal bei kleinen Projekten ohne Signatur-Zertifikat)
3. Assistent durchklicken, fertig. Kein Admin, kein Python, nichts weiter nötig.

Das Spiel prüft ab dann bei jedem Start selbst, ob es Updates gibt,
und installiert sie auf Knopfdruck.

## Steuerung

- **WASD / Pfeiltasten** fliegen, **Maus links / Leertaste** schießen
- **Q / E** Spezialfähigkeiten, **Shift** Afterburner
- Tastenbelegung frei änderbar: Einstellungen → Steuerung

## Multiplayer

Im Menü **SPIELEN → Gemeinsam (Koop)**: Online-Runde hosten oder per
Raumcode/Serverliste beitreten. LAN geht auch.
